Drop a new IFC model here (.ifc, or a .zip that contains one)

The file is converted in this browser and never uploaded anywhere. It is checked first (IFC schema, stones with TICKET NUMBER, geometry). Nothing changes until you press Replace the current model; if anything fails, the current model stays. The new model replaces the old one completely: there is no merging. A 1.4 GB IFC needs a computer with at least 8 GB of memory and takes several minutes.

Drop STL files or ZIP archives of STL files here

Each file must be named exactly like the IFC ticket number: TICKET.stl (binary or ASCII STL). Files for tickets that are not in the IFC model are rejected. A new file replaces the current one of that ticket. The IFC model is not changed or re-imported.

Drop Fab Sheet PDFs or ZIP archives of PDFs here

Accepted names: TICKET.pdf or TICKET - TICKET.pdf (extra sheets: TICKET__2.pdf). The ticket must be in the IFC model. A new file replaces the current sheet of that ticket.
